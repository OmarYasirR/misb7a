# 🕌 Digital Misbaha App

A simple and elegant digital Tasbeeh (سبحة) application built with JavaScript. Designed to help users perform daily dhikr (remembrance of Allah) with ease and mindfulness.

## 📌 Features

- ✅ Simple and intuitive user interface
- 🔢 Real-time counter with increment and reset functionality
- 🎨 Customizable themes (light/dark mode)
- 💾 Persistent count storage using localStorage
- 📱 Mobile-friendly and fully responsive design
- 🔔 Optional vibration feedback for each count (on supported devices)
- 📦 PWA support for offline usage and home screen installation

## 📱 PWA Support
- This app is fully PWA-compliant:

- Includes a manifest.json for installability

- Registers a service-worker.js for offline caching

- Prompts users to install the app on supported browsers

- To test PWA functionality:

1- Open the app in Chrome or Edge.

2- Use DevTools → Lighthouse → PWA audit.

3- Add to Home Screen and test offline mode.
  
## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Transitions)
- Vanilla JavaScript
- LocalStorage API
- Web Manifest for installability
- Service Worker for PWA

## 🧾 Usage
- Tap the main button to increment the count.

- Use the reset button to start over.

- Customize the dhikr phrase from the settings menu.

- Install the app to your device for offline use
